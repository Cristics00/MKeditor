# 2026-08-29

## build.bat 编码 bug 修复 + 重新打包
- 用户用方式A(双击 build.bat)打包,弹出乱码与 "Editor 不是内部或外部命令"、成功/失败信息同时出现 —— 不是正常打包。
- 根因: build.bat 含中文 + `chcp 65001`,在用户系统 cmd 下被按 UTF-8(无 BOM)误解析,导致命令 token 拆裂(`MKEditor`→`MK`+`Editor`)和 if/else 结构错乱,pyinstaller 实际未跑。
- 修复: 重写 build.bat 为纯 ASCII,直接用项目 Python `E:\python\python.exe -m PyInstaller MKEditor.spec --clean -y`(spec 已含 icon 与 assets/katex),并用 `cd /d "%~dp0"` 固定到项目目录。已验证可正常打包。
- 重新打包时遇到 `WinError 32 另一个程序正在使用此文件`(KaTeX 字体被锁): 多半是 Windows Defender 实时扫描 dist 内新文件,或资源管理器停在 dist 文件夹。解法: 把旧 `dist/MKEditor` 改名/移走(pyinstaller 新建干净输出目录绕过锁),再打包; 旧目录事后删掉。
- 最终产物: dist/MKEditor/MKEditor.exe(261MB,20 个 KaTeX 字体齐全)。
